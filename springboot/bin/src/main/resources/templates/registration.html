📋 How It Works

  1. Register: Enter your email address to start the registration process
  2. Verify: Check your email for a 6-digit verification code

  4. Manage: Use the management tools to delete users or clean up accounts
  5. Enjoy: Start using Pet Reminder App with your verified account!

  • You can delete individual users or multiple users at once
  • Use "Delete by Status" to clean up pending or unregistered accounts
  • Deletion actions cannot be undone - please be careful!
