📋 Usage Instructions

  • Speech Input: Click the microphone button and speak clearly. The text will appear in real-time.
  • Speech Output: Type or paste text, select a voice, adjust settings, and click the speaker button.
  • Keyboard Shortcuts: Hold Spacebar while focused on an input field to start voice input.
  • Browser Support: Chrome and Safari work best. Firefox has limited support.
  • Permissions: You may need to allow microphone access for speech input.
