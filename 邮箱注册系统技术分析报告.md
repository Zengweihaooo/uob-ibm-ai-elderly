## 🔐 验证码系统详解

### 1. 验证码生成器 (VerificationCodeGenerator)

#### 1.1 核心实现
```java
public class VerificationCodeGenerator {
    private static final SecureRandom random = new SecureRandom();
    private static final int CODE_LENGTH = 6;
    private static final int MIN_VALUE = 100000; // 6位数字最小值
    private static final int MAX_VALUE = 999999; // 6位数字最大值
    
    /**
     * 生成6位数字验证码
     */
    public static String generateCode() {
        int code = random.nextInt(MAX_VALUE - MIN_VALUE + 1) + MIN_VALUE;
        return String.valueOf(code);
    }
}
```

#### 1.2 技术特点
- **安全性**: 使用 `SecureRandom` 而非 `Random`
- **范围控制**: 确保生成100000-999999的6位数字
- **唯一性**: 每次生成不同的验证码
- **验证功能**: 提供格式验证方法

### 2. 验证码生命周期管理

#### 2.1 生成阶段
```java

```

#### 2.2 存储阶段
```java

userMapper.updateUserStatus(user.getId(), "PENDING");
```

#### 2.3 验证阶段
```java
public boolean verifyUser(String email, String code) {
    User user = userMapper.findByEmail(email);
    
    // 检查用户状态
    if (user == null || user.getStatus() != User.UserStatus.PENDING) {
        return false;
    }
    
    // 检查验证码是否过期
    if (user.isCodeExpired()) {
        return false;
    }
    
    // 验证码匹配检查
    if (code.equals(user.getVerificationCode())) {
        userMapper.updateVerificationStatus(user.getId(), "VERIFIED", LocalDateTime.now());
        user.verify();
        return true;
    }
    
    return false;
}
```

## 🔒 安全机制

### 1. 邮箱验证机制
```java
public EmailVerificationResult verifyEmailForRegistration(String email) {
    EmailVerificationResult result = new EmailVerificationResult();
    
    // 1. 基础格式验证
    ValidationResult formatResult = validateEmailFormat(email);
    if (!formatResult.isValid()) {
        result.setSuccess(false);
        result.setMessage(formatResult.getMessage());
        return result;
    }
    
    // 2. 域名验证
    ValidationResult domainResult = validateEmailDomain(email);
    if (!domainResult.isValid()) {
        result.setSuccess(false);
        result.setMessage(domainResult.getMessage());
        return result;
    }
    
    // 3. 重复检查
    ValidationResult duplicateResult = checkEmailDuplicate(email);
    if (!duplicateResult.isValid()) {
        result.setSuccess(false);
        result.setMessage(duplicateResult.getMessage());
        return result;
    }
    
    // 4. 安全检查
    ValidationResult securityResult = performSecurityChecks(email);
    if (!securityResult.isValid()) {
        result.setSuccess(false);
        result.setMessage(securityResult.getMessage());
        return result;
    }
    
    result.setSuccess(true);
    return result;
}
```

### 2. 防重复注册机制
```java
public User registerUser(String email) {
    email = email.trim().toLowerCase();
    User existingUser = userMapper.findByEmail(email);
    
    // 如果邮箱已存在且已验证，拒绝注册
    if (existingUser != null && existingUser.getStatus() == User.UserStatus.VERIFIED) {
        throw new IllegalArgumentException("该邮箱已被注册并验证，请使用其他邮箱或联系管理员重置");
    }
    
    // 如果邮箱存在但未验证，允许重新发送验证码
    if (existingUser != null) {
        // 更新现有用户的验证码
        user = existingUser;
    } else {
        // 创建新用户
        user = new User(email);
        userMapper.insert(user);
    }
}
```

## 🔧 API接口设计

### 1. 注册接口
```java
@PostMapping("/api/register")
@ResponseBody
public ResponseEntity<Map<String, Object>> registerUserAPI(@RequestParam("email") String email) {
    Map<String, Object> response = new HashMap<>();
    
    try {
        User user = userService.registerUser(email);
        response.put("success", true);
        response.put("message", "Verification email sent to: " + email);
        response.put("email", email);
        return ResponseEntity.ok(response);
    } catch (IllegalArgumentException e) {
        response.put("success", false);
        response.put("message", "Error: " + e.getMessage());
        return ResponseEntity.badRequest().body(response);
    }
}
```

### 2. 验证接口
```java
@PostMapping("/api/verify")
@ResponseBody
public ResponseEntity<Map<String, Object>> verifyUserAPI(@RequestParam("email") String email, 
                                                       @RequestParam("code") String code) {
    Map<String, Object> response = new HashMap<>();
    boolean verified = userService.verifyUser(email, code);
    
    if (verified) {
        response.put("success", true);
        response.put("message", "Email verification successful!");
    } else {
        response.put("success", false);
        response.put("message", "Invalid or expired verification code.");
    }
    
    response.put("email", email);
    return ResponseEntity.ok(response);
}
```

@ResponseBody
public ResponseEntity<Map<String, Object>> resendVerificationAPI(@RequestParam("email") String email) {

        response.put("message", "Failed to resend verification code: " + e.getMessage());
