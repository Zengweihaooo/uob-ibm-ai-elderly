# 提交日志模板 / Commit Log Template

**修改日期 / Modification Date**: YYYY-MM-DD

## 概述 / Overview
简要描述本次提交的主要目的和改动
Brief description of the main purpose and changes of this commit

## 文件操作 / File Operations

### 新建文件 / Created Files
- `path/to/file.ext` - 文件说明 / File description
  - 内容概述 / Content overview

### 修改文件 / Modified Files  
- `path/to/file.ext` - 修改说明 / Modification description
  - 在第X行添加了... / Added at line X...
  - 在第Y行修改了... / Modified at line Y...
  - 删除了第Z行的... / Deleted at line Z...

### 删除文件 / Deleted Files
- `path/to/file.ext` - 删除原因 / Deletion reason

## 功能变更 / Feature Changes

### 新增功能 / New Features
- 功能名称 / Feature name: 功能描述 / Feature description

### 修改功能 / Modified Features  
- 功能名称 / Feature name: 修改描述 / Modification description

### 删除功能 / Removed Features
- 功能名称 / Feature name: 删除原因 / Removal reason

## 技术细节 / Technical Details

### 依赖变更 / Dependency Changes
- 新增依赖 / Added dependencies: 
- 移除依赖 / Removed dependencies:
- 更新依赖 / Updated dependencies:

### 配置变更 / Configuration Changes
- 配置文件 / Config file: 变更内容 / Changes made

## 测试 / Testing
- 测试内容 / Test content
- 测试结果 / Test results

## 注意事项 / Notes
- 重要提醒 / Important reminders
- 已知问题 / Known issues
