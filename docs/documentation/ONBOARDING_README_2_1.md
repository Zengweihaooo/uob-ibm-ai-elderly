# 🎯 首次使用引导系统 (Onboarding Guide)

## 📋 功能概述

这是一个专为老年人设计的智能应用使用引导系统，帮助新用户快速了解和掌握应用的主要功能。系统采用渐进式引导方式，通过6个步骤详细介绍应用的核心特性。

## ✨ 主要特性

### 🎨 老年人友好设计
- **大字体显示**: 标题使用2.5rem，描述文字使用1.2rem
- **高对比度**: 白色背景配深色文字，确保清晰可读
- **简单图标**: 使用emoji图标，直观易懂
- **大按钮**: 按钮尺寸18px×36px，适合触摸操作

### 🔄 智能引导流程
1. **欢迎界面** - 介绍应用用途
2. **导航菜单** - 说明主要功能入口
3. **AI健康助手** - 介绍核心功能
4. **日程管理** - 说明日常管理功能
5. **语音交互** - 介绍语音功能
6. **开始使用** - 引导完成

### 🎯 交互方式
- **点击导航**: 下一步、上一步、跳过按钮
- **键盘支持**: 方向键、空格键、ESC键
- **高亮显示**: 当前功能区域高亮显示
- **进度指示**: 显示当前步骤和总进度

### ♿ 无障碍支持
- **屏幕阅读器**: 完整的ARIA标签支持
- **键盘导航**: 完整的键盘操作支持
- **高对比度模式**: 支持系统高对比度设置
- **减少动画**: 支持减少动画偏好设置

## 🚀 使用方法

### 首次使用
1. 打开应用主页 (`index.html`)
2. 系统自动检测首次使用
3. 延迟1秒后自动显示引导界面
4. 按照步骤完成引导

### 手动重新引导
1. 在导航栏点击"⚙️ 设置"
2. 在设置页面点击"🚀 重新引导"
3. 系统重新启动引导流程

### 清除引导记录
1. 进入设置页面
2. 点击"🗑️ 清除记录"
3. 下次打开应用会重新显示引导

### 核心类
```javascript
class OnboardingGuide {
    constructor()           // 初始化引导系统
```

## 🎨 自定义配置

### 修改引导步骤
在 `onboarding.js` 中修改 `steps` 数组：

```javascript
this.steps = [
    {
        icon: '👋',
        title: '自定义标题',
        description: '自定义描述',
        highlight: '.css-selector',  // 高亮元素选择器
        tooltip: '提示文字'          // 高亮提示
    }
    // ... 更多步骤
];
```

### 样式定制
在 `onboarding.css` 中修改样式变量：

```css
:root {
    --onboarding-primary: #007bff;
    --onboarding-secondary: #6c757d;
    --onboarding-background: rgba(0, 0, 0, 0.8);
}
```

### 触发条件
修改 `checkFirstTime()` 方法来自定义触发逻辑：

```javascript
checkFirstTime() {
    // 自定义触发条件
    const shouldShow = !localStorage.getItem('onboarding-completed') && 
                      !this.isReturningUser();
    if (shouldShow) {
        this.start();
    }
}
```

## 🐛 常见问题

### Q: 引导不自动显示
**A**: 检查localStorage中是否有`onboarding-completed`标记，或清除浏览器数据

### Q: 高亮元素位置不准确
**A**: 确保目标元素在DOM中存在，检查CSS选择器是否正确

### Q: 设置页面无法访问
**A**: 确认文件路径正确，检查JavaScript控制台是否有错误

### Q: 移动端显示异常
**A**: 检查CSS媒体查询，确保移动端样式正确加载
