# Important Date Reminder - README

(Identical to the previous version; maintained for versioning.)

## Overview

The Important Date Reminder feature adds intelligent email reminders to the IBM AI Elderly Companion System. It can automatically send reminder emails one week and one day before each important date.

## Key Features

### 🎯 Core Capabilities
- Dual reminders: one week and one day prior
- Smart date handling for yearly recurring dates (birthdays, anniversaries)
- HTML email templates with content by reminder type
- Daily scheduled checks at 8:00 AM
