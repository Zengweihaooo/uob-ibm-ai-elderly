# 备忘录功能说明

## 功能概述

备忘录功能是为老年用户设计的简单易用的记录工具，支持无分类、随时记录的小型备忘录，方便老年用户随手记下日常的各种想法、密码提示、待办事项。

## 主要功能

### 1. 备忘录管理
- **新增备忘录**: 支持创建一般备忘录、密码备忘录和待办事项
- **编辑备忘录**: 随时修改已创建的备忘录内容
- **删除备忘录**: 软删除，数据不会真正丢失
- **查看备忘录**: 清晰展示备忘录列表，支持搜索功能

### 2. 备忘录类型
- **📄 一般备忘录**: 记录日常想法、重要信息
- **🔐 密码备忘录**: 存储密码、账号等敏感信息，支持PIN码保护
- **📝 待办事项**: 记录需要完成的任务

### 3. 安全功能
- **PIN码保护**: 为密码备忘录提供额外的安全保护
- **本地PIN码**: 用户可以设置4位数字PIN码
- **加密显示**: 密码备忘录在列表中显示为加密状态

### 4. 搜索功能
- **关键词搜索**: 支持在标题和内容中搜索
- **实时搜索**: 输入时即时显示搜索结果
- **清空搜索**: 清空搜索框返回全部备忘录

### 5. 统计信息
- **总数统计**: 显示备忘录总数
- **分类统计**: 按类型统计备忘录数量
- **可视化展示**: 清晰的数据展示

## API接口说明

### 1. 创建备忘录
```
POST /api/memo/create
Content-Type: application/json

{
    "title": "备忘录标题",
    "content": "备忘录内容",
    "type": "general|password|todo"
}
```

### 2. 获取备忘录列表
```
GET /api/memo/list
```

### 3. 获取单个备忘录
```
GET /api/memo/{memoId}
```

### 4. 更新备忘录
```
PUT /api/memo/{memoId}
Content-Type: application/json

{
    "title": "新标题",
    "content": "新内容",
    "type": "general|password|todo"
}
```

### 5. 删除备忘录
```
DELETE /api/memo/{memoId}
```

### 6. 设置PIN码
```
POST /api/memo/set-pin
Content-Type: application/json

{
    "pinCode": "1234"
}
```

### 7. 验证PIN码
```
POST /api/memo/verify-pin
Content-Type: application/json

{
    "pinCode": "1234"
}
```

### 8. 获取加密备忘录内容
```
POST /api/memo/{memoId}/content
Content-Type: application/json

{
    "pinCode": "1234"
}
```

### 9. 搜索备忘录
```
GET /api/memo/search?keyword=搜索关键词
```

### 10. 获取统计信息
```
GET /api/memo/statistics
```

## 使用方法

### 1. 访问备忘录页面
在浏览器中访问 `http://localhost:8080/src/pages/memo.html`

### 2. 创建备忘录
1. 点击"➕ 新建备忘录"按钮
2. 填写备忘录标题和内容
3. 选择备忘录类型
4. 点击"保存"按钮

### 3. 设置PIN码
1. 点击"🔐 设置PIN码"按钮
2. 输入4位数字PIN码
3. 点击"设置PIN码"按钮

### 4. 查看加密备忘录
1. 点击加密备忘录的"🔓 查看"按钮
2. 输入PIN码
3. 查看备忘录内容

### 5. 搜索备忘录
1. 在搜索框中输入关键词
2. 系统会自动显示匹配的备忘录

### 6. 编辑备忘录
1. 点击备忘录的"✏️ 编辑"按钮
2. 修改标题、内容或类型
3. 点击"保存"按钮

### 7. 删除备忘录
1. 点击备忘录的"🗑️ 删除"按钮
2. 确认删除操作

## 技术实现

### 后端技术栈
- **Spring Boot**: 主框架
- **Java**: 编程语言
- **内存存储**: 使用ConcurrentHashMap存储数据（可扩展为数据库）

### 前端技术栈
- **HTML5**: 页面结构
- **CSS3**: 样式设计，支持响应式布局
- **JavaScript**: 交互逻辑
- **Fetch API**: 与后端通信

### 安全特性
- **PIN码验证**: 4位数字PIN码保护
- **输入验证**: 前后端双重验证
- **XSS防护**: HTML转义处理
- **软删除**: 数据不会真正丢失

## 注意事项

1. **PIN码安全**: PIN码仅用于本地验证，建议定期更换
2. **数据备份**: 当前使用内存存储，重启后数据会丢失
3. **网络连接**: 需要网络连接才能使用完整功能
4. **浏览器兼容**: 建议使用现代浏览器（Chrome、Firefox、Safari、Edge）

## 故障排除

### 1. 页面无法加载
- 检查网络连接
- 确认服务器是否启动
- 检查浏览器控制台错误信息

### 2. 备忘录无法保存
- 检查标题和内容是否填写
- 确认网络连接正常
- 查看浏览器控制台错误信息

### 3. PIN码验证失败
- 确认PIN码为4位数字
- 检查PIN码是否正确
- 尝试重新设置PIN码

### 4. 搜索无结果
- 确认搜索关键词正确
- 检查备忘录是否存在
- 尝试不同的关键词
